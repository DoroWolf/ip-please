# 玩法与规则

## 画面

- **上方**：请求在风控检查站前排队（一开场就爆满，不显示人数），出站后绿色向上是放行、红色向下是拒绝。上岗时有一段开场：黑屏打出日期，红队 clawd 带走检查站里的请求，你的 clawd 走进检查站（点击跳过）。无尽模式的顶部数据框在限时模式的时间右侧、以及三种模式的分数右侧各留一块提示位：限时模式在时间旁闪出 +5s / -30s、在分数旁闪出 +1（受处罚的一单不计分），完美模式常驻显示当前每单的加分（每分钟降一分时闪烁），耐力模式闪出 +1 / +2 / -5；提示闪烁 3 秒后消失。
- **左下 · 审查窗**：请求接入时显示 Ta 的网络头像（像素滤镜）、IP、昵称和请求类型（无尽模式难度 2 再加本次请求的使用设备与请求流量）；柜台上放着递过来的证件。请求摘要不在审查窗：它印在浏览器令牌上，没有浏览器令牌就看不到，接入者也不会主动说明来意。
- **右下 · 电脑桌面**：像个操作系统。证件拖到桌面上打开，拖回审查窗收起；右下角有手册、通告、历史记录、审查四个应用（手册 / 通告 / 历史记录再点一次图标就关掉）；任务栏列出桌面上的窗口（点一下最小化 / 还原）和系统日期。故事模式的顶栏只显示 `DAY x`，班次时间放在任务栏右下角：下班前一小时，时间会在黄色与白色之间闪烁提醒。证件和处罚通知只能最小化；指针碰到桌面右边缘会滑出 放行 / 拒绝 栏。审查模式下点击上方请求队列区域即可退出审查，窗口再多也不会挡住审查按钮。历史记录窗口记录当前这段对话（下一个请求进来时清空），浏览器令牌上的请求摘要（或历史记录里的请求内容）都可以在审查模式里和 API 授权的用途核对。

《规则手册》按章分页：一章内容超过一页时自动接续页，续页会重复章节标题（「支持地区」还会重复「地区 / 语言」表头），窗口高度保持固定，不会随内容一直长高。手册与通告的标题列右侧同时放英文副标与翻页列：英文副标（`CONSTITUTION` / `NOTICE`）在相对左边，`◀ 页码 ▶` 在相对右边；点左箭头回上一页、点右箭头翻到下一页，两边都会循环。手册底部的书签栏（目录 / 条例 / 地区 / 企业 / 签名）只在无尽模式显示；故事模式暂时停用（之后随剧情开放）。

无尽模式的世界观日期按难度推进：难度 1 是 2078.01.01，难度 2 是 2078.01.02，难度 3 是 2078.01.03。故事模式从 2077.11.30 开始。无尽模式每次上岗，桌面会先弹出安全部的官方通告：第 1 页底部印着安全部会话中心（凭证签发机构）的有效签名，接着是这一局的三名「特别关注对象」的头像（难度 2 在这之前多一页「新增证件」说明）。点第一次『下一位』之前，时间不会流逝。

## 一班的流程

下一位 → 把证件拖到桌面 → 对照《规则手册》和历史记录 →『审查』两项信息找矛盾（可以追问；结果会区分 矛盾 / 无矛盾 / 无关联）→ 把凭证拖进右侧的 放行 / 拒绝 栏盖章 → 把所有证件拖回审查窗的头像处还给对方，才算处理完。

盖章只是做出决定，交还证件前可以随时把凭证（或临时返回页）再拖到另一栏改选；证件全部交还、请求处理完毕后才判定对错、才会收到事故处罚。

柜台上的证件放不下时，图标会左右滚动：把指针停在柜台的左边缘或右边缘就会自动滚。

## 暂停与快捷键

`Esc` 暂停 / 继续。暂停界面只有『继续』和『主菜单』两个按钮。

无尽模式的快捷键：

- `Tab` / `Enter`：拉出 / 收起印章台（钉住后一直展开）。
- 快速双击：开关审查模式。

故事模式没有这些快捷键（`Esc` 暂停仍然可用）。

## 证件

凭证 / API 授权 / KYC 证明三种证件带数字签名（签发机构、签名、图案），须与手册「签名详情」一页的式样完全一致：凭证由安全部会话中心签发，API 授权由安全部接口管理处签发，KYC 证明由第三方「人格有限公司」核验签发；浏览器令牌没有签名。故事模式的凭证从第一天起就印签名，通告第 1 页底部也印同一组签发机构与签名，但这几天不会出伪造签名的请求（手册也还没有「签名详情」页）。

| 证件 | 内容 | 什么时候要 |
|---|---|---|
| 凭证 | 头像、IP、昵称、地区、有效期 | 每个请求 |
| 浏览器令牌 | IP、运营商（主要城市 · 运营商名）、语言代码、签发日期、有效期、请求摘要 | 个人账户（企业账户凭企业授权，无需浏览器令牌） |
| API 授权 | IP、用途、有效期 | 请求类型为 API 调用时 |
| 请求券 | 有效期 | 规则组启用请求券时，支持地区内的外国（美国、英国以外）请求 |
| 临时返回页 | 仅限用于拒绝请求 | 凭证缺失时，先用空柜台和条例审查出「凭证缺失」并点『询问』，系统才会派发到桌面上。不能代替凭证：可以照常盖章，但盖『放行』交还后一律判为事故（理由：凭证缺失） |

请求券没有签名，只登记有效期；对照任务栏的系统日期查验即可。美国和英国视为本国请求、无需请求券，支持地区里的其他国家（日本、德国、新加坡、法国、澳大利亚、加拿大）要持券。故事模式第四天起，请求券被窄版浏览器令牌取代：浏览器令牌登记 IP、运营商、签发日期、有效期与请求摘要，没有语言、时区，也没有签名。临时返回页同样没有签名，版面只印一行「仅限用于拒绝请求」，凭票让 Ta 回去补交凭证；没有凭证时必须先审查出「凭证缺失」并询问，系统才会把这张票放到桌面上。临时返回页不能代替凭证：可以照常盖章，但拿它盖『放行』，交还证件后一律判为事故，理由为凭证缺失。

请求摘要印在浏览器令牌上：前三天还没有浏览器令牌（这一单没交浏览器令牌时也一样），审查窗不显示请求内容，接入者也只会打个招呼、不会主动说明来意——你只能凭手里的证件决定放行或拒绝。放行后网关只会回一句「欢迎使用 Claude」。

无尽模式的条例还要求浏览器令牌的语言与凭证地区一致（浏览器令牌重新印时区时，时区也要一起核对）：目前浏览器令牌只印语言，拿浏览器令牌的「语言」和凭证的「地区」审查，或对照手册「支持地区」页的地区、语言两栏；不符时同样要先『询问』，之后可以拘留。浏览器令牌的「运营商」也要和凭证的「地区」审查：运营商印成「主要城市 · 运营商名」，主要城市不在凭证地区（例如凭证是「美国」、浏览器令牌却印「东京 · KESTREL」）就是不符，同样先『询问』，之后可以拘留。

## 常见问题

地区不支持（可拘留）、头像不符、IP / 昵称差一点、企业授权账号差一点、企业授权的凭证地区与签发企业所在地区不符（隐藏条例，对照企业名录，只能拒绝）、证件过期（对照任务栏日期）；KYC 记录过期（对照 KYC 证明与系统日期 / 通告，只能拒绝）、未满 13 岁（对照 KYC 出生日期与系统日期 / 通告，可拘留）、KYC 出生地与住址不符（隐藏规则视为伪造证件，可拘留；出生地和住址都可以是不支持地区）、KYC 出生地与凭证地区不符（先验证 SMS，通过则放行，不符可拘留）、KYC 住址与账单住址不符（先验证 SMS，通过则放行，不符可拘留）、付款账户是虚拟支付卡（可拘留）、支付凭证的账单地址 / 手机号与地区不符（先验证 SMS，通过则放行，不符可拘留）；证件签发日期晚于当前日期（隐藏规则，视为伪造证件，可拘留）、签名伪造、未出示凭证、浏览器令牌或环境信息卡、API 调用没带授权、API 授权用途与请求内容不符（对照浏览器令牌上的请求摘要，或历史记录里的请求内容）、浏览器令牌语言与凭证地区不符（对照手册「支持地区」页的地区、语言两栏，可拘留）、浏览器令牌运营商与凭证地区不符（运营商的主要城市不在凭证地区，可拘留）、外国请求没有请求券或请求券逾期、本人是特别关注对象（拿头像和通告第 2 页审查）。

## 验证 SMS

审查出异常后，先在审查结果上点『询问』；问过之后会自动退出审查模式（审查结果留在上方横幅，按钮固定为『已询问』），审查窗的第一个按钮（原本的『下一位』）才会变成『验证SMS』（`V`）。按下后按钮仍显示『验证SMS』但变暗锁定，桌面上会弹出一张空白的 SMS 表单，表单顶部单独印一行『将此表单交给用户』的提示（与下面的手机号栏位分开），把它拖到审查窗的头像上发给对方；对方报出手机号，表单填好后回到桌面，同时打印一份按凭证查到的「身份记录」（登记昵称、曾用名、手机——号码的国家码和格式随凭证地区而不同；没有曾用名时印「无」，底部注明「用户的手机与请求的昵称必须与此档案一致」）。

审查表单和档案上的手机号，或审查证件昵称 / 企业授权账号和曾用名：显示「身份已确认」说明只是本人换了头像 / 改了昵称 / 换了企业账号，应当放行；手机号不符或不是曾用名就是冒用。支付凭证的账单地址与 KYC 不符、手机号与地区不符、账单地址与地区不符、KYC 出生地与凭证地区不符、KYC 住址与账单住址不符，同样要先『验证SMS』：表单号码与身份记录一致就是本人，正常放行；不一致就是手机号与记录不符，询问这个新的手机号异常后可以拘留。曾用名印「无」的档案没有旧昵称可对，只能靠手机号确认。名称、头像、常用设备、请求流量、企业授权账号或支付凭证地址 / 手机号不符时，直接拒绝也是合规处置：只要审查出问题，按程序拒绝就视为正确处理（照常得分），不算事故。验证 SMS / 请求嗅探只用来确认能不能放行；确认没问题后放行即可。询问按钮按过之后会固定为『已询问』，措施按下后同样锁定；要再次使用措施，得先审查出另一个异常（审查结果上会重新出现『询问』），再询问它——同一异常不能重复询问。

## 拘留

只有规则组的 `redTeam` 为 true（左上的红队 clawd 进驻）时才开放；没有红队的天数不会出现『拘留』按钮，只能用放行 / 拒绝。`redGuards` 只让右侧岔路口的两位红队 clawd 出现，不开放拘留。

审查出签名伪造、签发日期在未来（伪造证件）、企业授权伪造（假图标或假企业名称）、KYC 出生地与住址不符（伪造证件）、身份矛盾（头像 / IP / 昵称 / 企业授权账号）、浏览器令牌语言与地区不符、浏览器令牌运营商与地区不符、使用设备不符、嗅探出特殊进程（运行爬虫或自动化脚本）、特别关注对象、凭证地区不在支持地区、未满 13 岁、付款账户是虚拟支付卡后，同样要先『询问』异常。证件过期或 KYC 记录过期只能拒绝，不能拘留。支付凭证的账单地址 / 手机号异常、KYC 出生地与凭证地区不符、KYC 住址与账单住址不符要先『验证SMS』：号对得上就放行；号对不上会产生手机号不符，询问后可以拘留。『验证SMS』『请求嗅探』与『拘留』共用审查窗的第一个按钮，优先序为 验证 SMS → 请求嗅探 → 拘留；按下后按钮仍显示『验证SMS』但变暗锁定。如果已经验证过 SMS 仍要拘留，就再审查出一个新的异常并询问，按钮才会重新变成『拘留』。

按下即切断连接、清掉桌面上和柜台上的全部证件，按钮直接回到『下一位』（不保留已按下状态），左上的红队 clawd 把请求从检查站里拖出来押走（岔路口的两位只是装饰），直接算正确处理。也可以照常拒绝，只是没有拘留奖励：限时模式 +5 秒，耐力模式该单共得 2 分（不是 1 + 2 分）。

## 模式

| 模式 | 规则 |
|---|---|
| 限时 | 现实时间 10 分钟内处理尽可能多的请求；每正确处理一个得 1 分（受处罚的一单不计分），每次事故损失 30 秒 |
| 完美 | 不允许出事，一次事故即结束；第一分钟内每个请求 10 分，之后每过一分钟少 1 分（十分钟后仍为 +1，不会降到 0 或负分） |
| 耐力 | 没有时间限制；正确处理一个请求 +1 token，操作失误 -5 token，Token 为负即停机；结算分数取本局到达过的最高 Token |
| 故事 | 每天：日期卡 → 读报 → 上岗 08:00 a.m.–12:00 p.m.（前三天，现实 2 分钟）／08:00 a.m.–03:00 p.m.（第四天起，现实 3 分钟）→ 下班结算电费 20、散热 10、训练数据 20；存款为负或连续三天宕机即停机。每天的条例、证件、通告和报纸见 `src/story.js` 的 `STORY`，打完最后一天显示「未完待续」 |

三种无尽模式的事故处罚单统一：第 1 次予以警告、第 2 次最后警告（皆暂不处罚），第 3／4 次罚款 5 token，之后每次 +5 token。处罚单不再列出各模式原有的惩罚文案。

三种无尽模式的结束画面完全统一：标题「游戏结束」（固定青色，不会因为失败变成红字），只显示得分（耐力取本局到达过的最高 Token），并配同一首结束曲（不播坏结局的曲子），不显示事故原因的红字。达到结束条件时只响一次下班铃（队伍留在原地，不散开）：限时模式不再进件，把手头上的请求审完才结算；完美 / 耐力模式则等 2 秒后结算。

## 无尽模式的难度

在标题画面进入无尽模式后，这一页不显示标题：上面是三张玩法卡（限时 / 完美 / 耐力），下面是三档难度（证件说明直接写在难度按钮里）；先点玩法、再选难度，最后点页面底部的『确定』开局。三种玩法的最佳纪录按难度分开记。

| 难度 | 证件与条例 |
|---|---|
| 难度 1 | 上面介绍的全套：凭证、浏览器令牌、API 授权 |
| 难度 2 | 难度 1 的全部，再加上环境信息卡、企业授权与「不得运行爬虫或自动化脚本」条例 |
| 难度 3 | 难度 2 的全部，再加上支付凭证与 KYC 证明（世界观日期 2078.01.03） |

**环境信息卡**（仿照《Papers, Please》的身份信息卡）登记这个账户的环境档案：时区、常用设备、平均流量。个人账户的请求都要出示（条例改为「每个请求需出示凭证」与「个人账户需出示浏览器令牌和环境信息卡」），没带就是「环境信息卡缺失」。时区要和凭证地区一致：手册「支持地区」页重新列出时区一栏，条例也写回「语言和时区须与地区一致」；拿卡上的「时区」和凭证的「地区」审查，不符时可以询问后拘留。常用设备和平均流量对照审查窗里本次请求的「设备」「流量」两栏：

- **设备不符**：拿审查窗的「设备」和卡上的「常用设备」审查。询问后可以『验证 SMS』：手机号对得上就是本人换了设备，应当放行；手机号不符就是冒用，询问后可以拘留。
- **流量异常**：请求流量是平均流量的好几倍（正常请求只会在平均值上下浮动）。询问后审查窗第一个按钮变成『请求嗅探』，按下后要等 5–10 秒，桌面才会打印一份「嗅探报告」（请求流量、前台进程、后台进程）。拿「后台进程」和手册条例「不得运行爬虫或自动化脚本」审查：后台是认得出的常见进程（OneDrive / Google Drive 云盘同步、Zoom / Teams 视频通话、系统更新、上传附件）就显示「无特殊进程」，应当放行；后台是认不得的奇怪名称（如 autoclaw.exe、scrapebot、reqflood.sh、tokenfarm.exe、crawlr.py）就是「发现特殊进程」，询问后可以拘留。流量异常本身不能拘留，要先嗅探出特殊进程。

**企业授权**（仿照外交授权）：企业账户须出示凭证和含 Anthrotzka 的企业授权，不需要浏览器令牌、环境信息卡，也不受地区限制；企业账户也不需要支付凭证（公司已完成支付验证），但难度 3 仍须出示 KYC 证明。审查窗的请求类型一律显示「企业请求」，企业请求也没有具体的请求概述。授权顶部印着签发企业的图标和名称，下面是账号、IP 和授权企业：

- 企业授权必须写明 Anthrotzka；「授权企业」一栏没有 Anthrotzka 的授权书视为无效证件，只能拒绝（审查模式拿「授权企业」和「企业账户须出示…」的条例比对）。
- 账号要和凭证昵称 / 本人一致，IP 要和本人一致。账号不符同样要先『验证 SMS』（企业授权的账号可能只是本人的旧账号）：身份记录的曾用名里有这个旧账号、手机号也对得上，就是本人换过企业账号，应当放行；不是曾用名或手机号不符就是冒用，询问后可以拘留。IP 不符则直接询问后拘留。
- 横幅上的企业名称和图标要和手册「企业名录」一致：伪造的授权会印山寨名称（如 OpenMlnd、Anthrotska）或改过几个像素的图标，拿横幅和企业名录比对即可查出「企业授权伪造」，询问后可以拘留。DeepThink 的授权一律无效，但也可能带伪造：拿到山寨横幅时照样可以拘留。
- 凭证本身照常核对：头像、IP、有效期、签名、特别关注对象。
- 签发企业的所在地区一般就是凭证地区。手册新增「三、企业名录」，按印刷顺序列出六家企业：Anthrotzka、OpenMind、Googol、yAI（美国），Mistrain（法国），DeepThink（中国大陆）。Anthrotzka 是本国的网关运营方，只出现在授权的「授权企业」一栏，不会自己签发企业授权（访问自家服务不经过这道外部网关）。DeepThink 的企业授权必定不含 Anthrotzka，因此一律视为无效证件，只能拒绝；它的凭证地区（中国大陆）同时不在支持地区，这是另一个独立疑点：审查「凭证地区 / 支持地区」会出现「地区不支持」，两个疑点可以分别询问、分别处置（授权无效只能拒绝；地区不支持询问后可以拘留）。DeepThink 的用户也可能被列为特别关注对象或拿着伪造授权：这两类疑点照常出现，询问后可以拘留。
- 隐藏条例「企业账户的凭证地区须与企业所在地区一致」（不印在手册上）：拿凭证的「地区」核对授权顶部签发企业在手册「企业名录」上的所在地区，两者不符就是「地区与企业不符」，只能拒绝。签发企业不是 DeepThink 时才会出这类单子（DeepThink 的授权无效另有疑点）。

难度 3 的凭证多印一栏「套餐」（free / pro / max），手册条例改为「每个请求需出示凭证和 KYC 证明」，新增「个人付费套餐与 API 调用需出示支付凭证」「支付凭证须与凭证及 KYC 证明一致」「付款账户不得为虚拟支付卡」「用户须年满 13 岁」；KYC 证明上注明「KYC 记录三年内有效」（手册不印这条）；「支持地区」页多一栏手机区号。KYC 证明的出生地与住址必须在同一个地区（都可以是不支持地区，不使用朝鲜）；不符视为伪造证件，可以拘留。KYC 出生地与凭证地区不符、KYC 住址与账单住址不符时先验证 SMS；出生地不与账单住址比对。

**支付凭证**：个人账户的非 free 套餐和 API 调用都要出示（free 套餐的对话请求不需要；企业账户由公司完成支付验证，不需要支付凭证），登记 IP、付款账户、账单地址、手机号：

- IP 要和本人 / 凭证一致（和其他证件的 IP 不符一样，询问后可以拘留）。
- 账单地址印成「城市 · 街道 门牌号」，城市要在凭证地区；手机号的国家码要是凭证地区的（对照「支持地区」页的区号）。不符时询问后先验证 SMS；号对得上就放行，对不上就是手机号与记录不符，询问后可以拘留。
- 账单地址要和 KYC 证明的住址一致；KYC 住址可以和账单地址在同一个地区的不同街道，也可以在别的地区（出生地同地区）。不符时先验证 SMS；号对得上就放行，对不上就是手机号与记录不符，询问后可以拘留。出生地不与账单地址比对。
- 付款账户印成「发卡方 ·尾号」，虚拟卡的发卡方后面会印「（虚拟）」，看到就是虚拟支付卡，询问后可以拘留。
- 没带支付凭证：拿柜台（或凭证的「套餐」、API 调用的「类型」）和条例审查，只能拒绝。
- 验证 SMS 时，身份记录上的手机号就是支付凭证登记的号码。

**KYC 证明**（仿照护照）：所有请求都要出示（企业账户也一样）。上方是人像、真实姓名、出生地、住址、出生日期，其中人像与真实姓名只是装饰、不能审查；下方是 KYC 更新记录（最新的在最上面）；最下方是第三方「人格有限公司」的核验签名（对照手册「签名详情」页）：

- 出生地和住址必须在同一个地区；两者都可以是不支持地区（证件内容不使用朝鲜）。出生地与住址不符时，隐藏规则视为伪造证件：询问后可以拘留。
- KYC 住址可以不在凭证地区；账单地址仍在凭证地区。KYC 出生地与凭证地区不符、KYC 住址与账单地址不符时，都先验证 SMS：号码对得上就是本人，正常放行；对不上就是手机号与记录不符，询问后可以拘留。出生地不与账单地址比对。
- 出生日期对照系统日期，须年满 13 岁（刚好 13 岁生日当天算满），未满询问后可以拘留。
- 最近一次 KYC 更新须在三年之内（刚好三年整仍有效），超过只能拒绝。这条不印在手册上，而是印在 KYC 证明底部；拿「KYC 更新记录」和任务栏的系统日期或通告的日期比对。
- 底部的核验签名由「人格有限公司」签发，须与手册「签名详情」页一致；签名伪造可以拘留。
- 没带 KYC 证明：拿柜台和「每个请求需出示凭证和 KYC 证明」审查，只能拒绝。
