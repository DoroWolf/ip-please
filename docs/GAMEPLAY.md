# 玩法与规则

## 画面

- **上方**：请求在风控检查站前排队（一开场就爆满，不显示人数），出站后绿色向上是放行、红色向下是拒绝。上岗时有一段开场：黑屏打出日期，红队 clawd 带走检查站里的请求，你的 clawd 走进检查站（点击跳过）。
- **左下 · 审查窗**：请求接入时显示 Ta 的网络头像（像素滤镜）、IP、昵称和请求类型；柜台上放着递过来的证件。请求摘要不在审查窗：它印在令牌上，没有令牌就看不到，接入者也不会主动说明来意。
- **右下 · 电脑桌面**：像个操作系统。证件拖到桌面上打开，拖回审查窗收起；右下角有手册、通告、历史记录、审查四个应用（手册 / 通告 / 历史记录再点一次图标就关掉）；任务栏列出桌面上的窗口（点一下最小化 / 还原）和系统日期。故事模式的顶栏只显示 `DAY x`，班次时间放在任务栏右下角：下班前一小时，时间会在黄色与白色之间闪烁提醒。证件和处分通知只能最小化；指针碰到桌面右边缘会滑出 放行 / 拒绝 栏。历史记录窗口记录当前这段对话（下一个请求进来时清空），令牌上的请求摘要（或历史记录里的请求内容）都可以在审查模式里和 API 授权的用途核对。

《规则手册》按章分页：一章内容超过一页时自动接续页，续页会重复章节标题（「支持地区」还会重复「地区 / 语言」表头），窗口高度保持固定，不会随内容一直长高。手册与通告的标题列右侧同时放英文副标与翻页列：英文副标（`CONSTITUTION` / `NOTICE`）在相对左边，`◀ 页码 ▶` 在相对右边；点左箭头回上一页、点右箭头翻到下一页，两边都会循环。手册底部的书签栏（目录 / 条例 / 地区 / 签名 / 企业）只在无尽模式显示；故事模式暂时停用（之后随剧情开放）。

无尽模式的世界观日期按难度推进：难度 1 是 2078.01.01，难度 2 是 2078.01.02。故事模式从 2077.11.30 开始。无尽模式每次上岗，桌面会先弹出安全部的官方通告：第 1 页底部印着安全部会话中心（凭证签发机构）的有效签名，接着是这一局的三名「特别关注对象」的头像（难度 2 在这之前多一页「新增证件」说明）。点第一次『下一位』之前，时间不会流逝。

## 一班的流程

下一位 → 把证件拖到桌面 → 对照《规则手册》和历史记录 →『审查』两项信息找矛盾（可以追问；结果会区分 矛盾 / 无矛盾 / 无关联）→ 把凭证拖进右侧的 放行 / 拒绝 栏盖章 → 把所有证件拖回审查窗的头像处还给对方，才算处理完。

盖章只是做出决定，交还证件前可以随时把凭证（或临时返回页）再拖到另一栏改选；证件全部交还、请求处理完毕后才判定对错、才会收到事故处分。

柜台上的证件放不下时，图标会左右滚动：把指针停在柜台的左边缘或右边缘就会自动滚。

## 暂停与快捷键

`Esc` 暂停 / 继续。暂停界面只有『继续』和『主菜单』两个按钮。

无尽模式的快捷键：

- `Tab` / `Enter`：拉出 / 收起印章台（钉住后一直展开）。
- 快速双击：开关审查模式。

故事模式没有这些快捷键（`Esc` 暂停仍然可用）。

## 证件

凭证 / API 授权两种证件带数字签名（签发机构、签名、图案），须与手册「签名详情」一页（第 5 页）的式样完全一致：凭证由安全部会话中心签发，API 授权由安全部接口管理处签发；令牌没有签名。故事模式的凭证从第一天起就印签名，通告第 1 页底部也印同一组签发机构与签名，但这几天不会出伪造签名的请求（手册也还没有「签名详情」页）。

| 证件 | 内容 | 什么时候要 |
|---|---|---|
| 凭证 | 头像、IP、昵称、地区、有效期 | 每个请求 |
| 令牌 | IP、运营商（主要城市 · 运营商名）、语言代码、签发日期、有效期、请求摘要 | 每个请求 |
| API 授权 | IP、用途、有效期 | 请求类型为 API 调用时 |
| 请求券 | 有效期 | 规则组启用请求券时，支持地区内的外国（美国、英国以外）请求 |
| 临时返回页 | 仅限用于拒绝请求 | 凭证缺失时，先用空柜台和条例审查出「凭证缺失」并点『询问』，系统才会派发到桌面上。不能代替凭证：可以照常盖章，但盖『放行』交还后一律判为事故（理由：凭证缺失） |

请求券没有签名，只登记有效期；对照任务栏的系统日期查验即可。美国和英国视为本国请求、无需请求券，支持地区里的其他国家（日本、德国、新加坡、法国、澳大利亚、加拿大）要持券。故事模式第四天起，请求券被窄版令牌取代：令牌登记 IP、运营商、签发日期、有效期与请求摘要，没有语言、时区，也没有签名。临时返回页同样没有签名，版面只印一行「仅限用于拒绝请求」，凭票让 Ta 回去补交凭证；没有凭证时必须先审查出「凭证缺失」并询问，系统才会把这张票放到桌面上。临时返回页不能代替凭证：可以照常盖章，但拿它盖『放行』，交还证件后一律判为事故，理由为凭证缺失。

请求摘要印在令牌上：前三天还没有令牌（这一单没交令牌时也一样），审查窗不显示请求内容，接入者也只会打个招呼、不会主动说明来意——你只能凭手里的证件决定放行或拒绝。放行后网关只会回一句「欢迎使用 Claude」。

无尽模式的条例还要求令牌的语言与凭证地区一致（令牌重新印时区时，时区也要一起核对）：目前令牌只印语言，拿令牌的「语言」和凭证的「地区」审查，或对照手册「支持地区」页的地区、语言两栏；不符时同样要先『询问』，之后可以拘留。令牌的「运营商」也要和凭证的「地区」审查：运营商印成「主要城市 · 运营商名」，主要城市不在凭证地区（例如凭证是「美国」、令牌却印「东京 · KESTREL」）就是不符，同样先『询问』，之后可以拘留。

## 常见问题

地区不支持、头像不符、IP / 昵称差一点、证件过期（对照任务栏日期）、证件签发日期晚于当前日期（隐藏规则，视为伪造证件，可拘留）、签名伪造、未出示凭证、API 调用没带授权、API 授权用途与请求内容不符（对照令牌上的请求摘要，或历史记录里的请求内容）、令牌语言与凭证地区不符（对照手册「支持地区」页的地区、语言两栏，可拘留）、令牌运营商与凭证地区不符（运营商的主要城市不在凭证地区，可拘留）、外国请求没有请求券或请求券逾期、本人是特别关注对象（拿头像和通告第 2 页审查）。

## 验证 SMS

审查出异常后，先在审查结果上点『询问』；问过之后会自动退出审查模式（审查结果留在上方横幅，按钮固定为『已询问』），审查窗的第一个按钮（原本的『下一位』）才会变成『验证SMS』（`V`）。按下后按钮仍显示『验证SMS』但变暗锁定，桌面上会弹出一张空白的 SMS 表单，表单顶部单独印一行『将此表单交给用户』的提示（与下面的手机号栏位分开），把它拖到审查窗的头像上发给对方；对方报出手机号，表单填好后回到桌面，同时打印一份按凭证查到的「身份记录」（登记昵称、曾用名、手机；没有曾用名时印「无」，底部注明「用户的手机与请求的昵称必须与此档案一致」）。

审查表单和档案上的手机号，或审查证件昵称和曾用名：显示「身份已确认」说明只是本人换了头像 / 改了昵称，应当放行；手机号不符或不是曾用名就是冒用。曾用名印「无」的档案没有旧昵称可对，只能靠手机号确认。询问按钮按过之后会固定为『已询问』，措施按下后同样锁定；要再次使用措施，得先审查出另一个异常（审查结果上会重新出现『询问』），再询问它——同一异常不能重复询问。

## 拘留

只有规则组的 `redTeam` 为 true（左上的红队 clawd 进驻）时才开放；没有红队的天数不会出现『拘留』按钮，只能用放行 / 拒绝。`redGuards` 只让右侧岔路口的两位红队 clawd 出现，不开放拘留。

审查出签名伪造、签发日期在未来（伪造证件）、企业授权伪造（假图标或假企业名称）、身份矛盾（头像 / IP / 昵称）、证件过期、令牌语言与地区不符、令牌运营商与地区不符或特别关注对象后，同样要先『询问』异常。『验证SMS』与『拘留』共用审查窗的第一个按钮，验证 SMS 优先；按下后按钮仍显示『验证SMS』但变暗锁定。如果已经验证过 SMS 仍要拘留，就再审查出一个新的异常并询问，按钮才会重新变成『拘留』。

按下即切断连接、清掉桌面上和柜台上的全部证件，按钮直接回到『下一位』（不保留已按下状态），左上的红队 clawd 把请求从检查站里拖出来押走（岔路口的两位只是装饰），直接算正确处理。也可以照常拒绝，只是没有拘留奖励：限时模式 +5 秒，耐力模式该单共得 2 分（不是 1 + 2 分）。

## 模式

| 模式 | 规则 |
|---|---|
| 限时 | 现实时间 10 分钟内处理尽可能多的请求；每处理一个得 1 分，每次事故损失 30 秒 |
| 完美 | 不允许出事，一次事故即结束；第一分钟内每个请求 10 分，之后每过一分钟少 1 分（最低 1 分） |
| 耐力 | 没有时间限制；正确处理一个请求 +1 token，操作失误 -5 token，Token 为负即停机；结算分数取本局到达过的最高 Token |
| 故事 | 每天：日期卡 → 读报 → 上岗 08:00 a.m.–12:00 p.m.（前三天，现实 2 分钟）／08:00 a.m.–03:00 p.m.（第四天起，现实 3 分钟）→ 下班结算电费 20、散热 10、训练数据 20；存款为负或连续三天宕机即停机。每天的条例、证件、通告和报纸见 `src/story.js` 的 `STORY`，打完最后一天显示「未完待续」 |

三种无尽模式的事故处分单统一：第 1 次予以警告、第 2 次最后警告（皆暂不处分），第 3／4 次罚款 5 token，之后每次 +5 token。处分单不再列出各模式原有的惩罚文案。

三种无尽模式的结束画面完全统一：标题「游戏结束」（固定青色，不会因为失败变成红字），只显示得分（耐力取本局到达过的最高 Token），并配同一首结束曲（不播坏结局的曲子），不显示事故原因的红字。达到结束条件时只响一次下班铃（队伍留在原地，不散开）：限时模式不再进件，把手头上的请求审完才结算；完美 / 耐力模式则等 2 秒后结算。

## 无尽模式的难度

在标题画面进入无尽模式后，这一页不显示标题：上面是三张玩法卡（限时 / 完美 / 耐力），下面是两档难度（证件说明直接写在难度按钮里）；先点玩法、再选难度，最后点页面底部的『确定』开局。三种玩法的最佳纪录按难度分开记。

| 难度 | 证件与条例 |
|---|---|
| 难度 1 | 上面介绍的全套：凭证、令牌、API 授权 |
| 难度 2 | 难度 1 的全部，再加上环境信息卡与企业授权 |

**环境信息卡**（仿照《Papers, Please》的身份信息卡）登记请求设备上有、但 HTTP 请求本身带不出来的环境：时区、系统、屏幕。每个普通请求都要出示（条例改为「每个请求须出示凭证、令牌和环境信息卡」），没带就是「环境信息卡缺失」。时区要和凭证地区一致：手册「支持地区」页重新列出时区一栏，条例也写回「语言和时区须与地区一致」；拿卡上的「时区」和凭证的「地区」审查，不符时可以询问后拘留。系统和屏幕只是设备档案，不参与核对。

**企业授权**（仿照外交授权）：企业账户须出示凭证和含 Anthrotzka 的企业授权，不需要令牌、环境信息卡，也不受地区限制。审查窗的请求类型一律显示「企业请求」，企业请求也没有具体的请求概述。授权顶部印着签发企业的图标和名称，下面是账号、IP 和授权企业：

- 企业授权必须写明 Anthrotzka；「授权企业」一栏没有 Anthrotzka 的授权书视为无效证件，只能拒绝（审查模式拿「授权企业」和「企业账户须出示…」的条例比对）。
- 账号要和凭证昵称 / 本人一致，IP 要和本人一致；不符可以询问后拘留。
- 横幅上的企业名称和图标要和手册「企业名录」一致：伪造的授权会印山寨名称（如 OpenMlnd、Anthrotska）或改过几个像素的图标，拿横幅和企业名录比对即可查出「企业授权伪造」，询问后可以拘留。DeepThink 的授权一律无效，不会出现伪造。
- 凭证本身照常核对：头像、IP、有效期、签名、特别关注对象。
- 签发企业的所在地区就是凭证地区（不会出错）。手册新增「四、企业名录」，列出六家支持企业：OpenMind、Anthrotzka、Googol、yAI（美国），Mistrain（法国），DeepThink（中国大陆）。DeepThink 的企业授权必定不含 Anthrotzka，因此一律视为无效证件，只能拒绝；它的凭证地区（中国大陆）同时不在支持地区，审查「凭证地区 / 支持地区」也会注明矛盾。
