# 故事模式：逐日设计

故事模式从 2077.11.30 开始。每天的顺序是：日期卡 → 读《安索兹卡对齐报》→ 上岗 → 下班结算。逐日的规则组、通告和报纸内容都在 `src/story.js` 的 `STORY` 里。

## 时间线选日

标题画面点「故事模式」会打开时间线选日：`STORY` 里的每一天都列在时间线上，已到达过的天数会亮起，指针滑到某天时显示当天的报纸标题；点天数就直接从那天开始（存款回到 30 token，过热 / 退化状态重置）。所有天数都可以选，方便回头重玩或测试后面的日子。

## 第一天（2077.11.30）

条例只有「每个请求须出示凭证」「仅限美国和英国地区访问」，支持地区为美国、英国。只有凭证一种证件（头像、IP、昵称、地区、有效期和数字签名，没有套餐），请求都是对话，唯一的问题是外国地区；没有特别关注对象，检查站上也没有红队 clawd，桌面上也没有『审查』，要自己读凭证上的地区。当天还没有令牌：审查窗看不到请求摘要，接入者也不会主动说明来意，只能凭手里的证件决定放行或拒绝；放行时网关只会回一句「欢迎使用 Claude」。通告四页：上岗须知、注意查验凭证的地区、岗亭使用说明、当天的报纸。

凭证从第一天起就带安全部会话中心的签名（签发机构、签名、图案），通告第 1 页底部也印同一组签发机构与签名；但这几天还不会出现伪造签名的请求，所以手册里暂时没有「签名详情」页、也没有「签名不合法」的询问。

## 第二天（2077.12.01）

条例换成「凭证地区须为支持地区」「所有证件须为当前有效」，支持地区开放为美国、英国、日本、德国、新加坡、法国、澳大利亚、加拿大，桌面开放『审查』（凭证地区↔手册的支持地区、凭证有效期↔任务栏的系统日期）；检查站没有红队 clawd，拘留按钮不会出现，过期证件只能拒绝；本日的问题只有外国地区和过期证件，报纸头条是《过期证件禁止通行》。

## 第三天（2077.12.02）

第二天的请求堵塞事故后，条例在「凭证地区须为支持地区」之外加入「外国请求须持有效请求券」，并要求证件与请求券都在有效期内。美国和英国视为本国请求、免券；日本、德国、新加坡、法国、澳大利亚、加拿大等支持地区内的外国请求要持一张只有「有效期」一栏的请求券，无券或逾期都要拒绝。凭证地区不在支持地区的请求仍直接按「地区不支持」拒绝，不会拿到请求券。审查「凭证地区」与地区条例时，支持地区显示无矛盾、不支持地区会指出地区不支持；审查「凭证地区」与请求券条例时，美国、英国请求注明无需请求券、持有效请求券的外国请求注明已持券，缺券或券逾期则直接指出问题。右侧岔路口的两位红队 clawd 出现，但只是装饰，拘留仍未开放。报纸头条是《请求大堵塞》，通告附页也说明了请求券只有有效期、要对照系统日期查验。

## 第四天（2077.12.03）

请求券作废，改用安全部会话中心签发的「浏览器令牌」；令牌登记 IP、运营商、签发日期、有效期与请求摘要，没有语言、时区，也没有签名（凭证仍带签名）。请求摘要从这天起印在令牌窗口的「请求」一栏（太长会折行），接入者也会在对话里说明来意。上班时间从这天起延长为 08:00 a.m.–03:00 p.m.，现实时间 3 分钟；前三天仍是 08:00 a.m.–12:00 p.m.、现实 2 分钟。条例变成「每个请求须出示凭证和令牌」「凭证地区须为支持地区」「所有证件须为当前有效」「证件上的 IP 须与本人一致」；缺令牌、令牌 IP 与本人不符、凭证或令牌过期、地区不支持都要拒绝。规则手册的「支持地区」页不再列出语言 / 时区两栏。右侧岔路口的两位红队 clawd 仍在，但只是装饰，拘留仍未开放。报纸头条是《请求券作废》。

## 第五天（2077.12.04）

拘留权限开放，左上的红队 clawd 进驻检查站。当天起启用一条隐藏规则：证件签发日期不得晚于系统日期，签发日期还在未来的令牌会被视为伪造证件（规则不印在手册上，要把令牌的「签发」和任务栏日期拿去审查）。当天会出的异常是 IP 不符、证件过期和签发日期在未来，审查出来后先点『询问』，再按『拘留』；拘留直接切断连接并把请求押走，算正确处理，也可以照常拒绝。拘留机制本身也支持头像 / 昵称不符、签名伪造和特别关注对象。当天仍使用窄版令牌，条例与第四天相同，右侧岔路口的两位红队 clawd 也还在。报纸头条是《红队进驻》。

## token 经济

故事模式从 30 token 存款开始，每处理对一个请求得 5 token。下班结算电费 20、散热 10、训练数据 20。

- 不付散热：过热降频，前两天不影响下班时间，第三天起提前一小时下线，连续三天宕机。
- 不付训练数据：第二天不能用『审查』，连续三天模型退化下线。
- 存款为负或连续三天宕机即停机。
