<h1 align="center">IP, PLEASE · 风控检查站</h1>

<p align="center">
  Papers, Please 风格的像素小游戏。<br>
  你是一个部署在入口网关前的风控小模型。每一个请求都要先经过你，才能到达模型：放行合规的，拦截违规的。
</p>

- 故事模式：每天先读《安索兹卡真理报》，再按当天的条例上岗（目前做到第五天）
- 无尽模式：限时 / 完美 / 耐力三种玩法
- 手机横屏用手指、电脑用鼠标；也支持键盘
- 纯静态网页，不加载任何外部资源；下载仓库后直接双击 `index.html` 也能玩

## 画面

- **上方**：请求在风控检查站前排队（一开场就爆满，不显示人数），出站后绿色向上是放行、红色向下是拦截。上岗时有一段开场：黑屏打出日期，红队 clawd 带走检查站里的请求，你的 clawd 走进检查站（点击跳过）
- **左下 · 审查窗**：请求接入时显示 Ta 的网络头像（像素滤镜）、IP、昵称、请求类型和摘要；柜台上放着递过来的证件
- **右下 · 电脑桌面**：像个操作系统。证件拖到桌面上打开，拖回审查窗收起；右下角有手册、通告、历史记录、比对四个应用（手册 / 通告 / 历史记录再点一次图标就关掉）；任务栏列出桌面上的窗口（点一下最小化 / 还原）和系统日期。证件和处分通知只能最小化；指针碰到桌面右边缘会滑出 放行 / 拦截 栏。历史记录窗口记录当前这段对话（下一个请求进来时清空），审查窗的请求摘要（或历史记录里的请求内容）都可以在比对模式里和 API 授权的用途核对

无尽模式的世界观日期是 2078.01.01，故事模式从 2077.11.30 开始。无尽模式每次上岗，桌面会先弹出安全部的官方通告：第 1 页底部印着安全部会话中心（令牌签发机构）的有效签名指纹，第 2 页是这一局的三名「特别关注对象」的头像。点第一次『下一位』之前，时间不会流逝。

## 玩法

下一位 → 把证件拖到桌面 → 对照《规则手册》和历史记录 →『比对』两项信息找矛盾（可以追问；结果会区分 矛盾 / 无矛盾 / 无关联）→ 把凭证拖进右侧的 放行 / 拦截 栏盖章 → 把所有证件拖回审查窗的头像处还给对方，才算处理完。

盖章只是做出决定，交还证件前可以随时把凭证（或临时返回票）再拖到另一栏改选（`A` / `D` 也可以直接改）；证件全部交还、请求处理完毕后才判定对错、才会收到事故处分。

凭证 / 令牌 / API 授权三种证件带数字签名（签发机构、指纹、图案），须与手册「签名详情」一页（第 5 页）的式样完全一致：

| 证件 | 内容 | 什么时候要 |
|---|---|---|
| 凭证 | 头像、IP、昵称、地区、套餐（free / pro / max）、有效期 | 每个请求 |
| 令牌 | IP、语言代码、时区、签发日期、有效期 | 每个请求 |
| API 授权 | 持有人、IP、用途、有效期 | 请求类型为 API 调用时 |
| 请求券 | 有效期 | 规则组启用请求券时，凭证地区不在支持地区的外国请求 |
| 临时返回票 | 事由、签发日期、备注 | 凭证缺失时，先用空柜台和条例比对出「凭证缺失」并点『询问』，系统才会派发到桌面上。不能代替凭证：可以照常盖章，但盖『放行』交还后一律判为事故（理由：凭证缺失），正确做法是盖『拦截』让 Ta 回去补交凭证 |

请求券没有签名，只登记有效期；对照任务栏的系统日期查验即可。故事模式第四天起，请求券被窄版令牌取代：令牌只登记 IP、签发日期与有效期，没有语言、时区，也没有签名指纹。临时返回票同样没有签名，凭票返回补交凭证；没有凭证时必须先比对出「凭证缺失」并询问，系统才会把这张票放到桌面上。临时返回票不能代替凭证：可以照常盖章，但拿它盖『放行』，交还证件后一律判为事故，理由为凭证缺失。

常见问题：地区不支持、头像不符、IP / 昵称差一点、证件过期（对照任务栏日期）、证件签发日期晚于当前日期（隐藏规则，视为伪造证件，可拘留）、签名伪造、未出示凭证、API 调用没带授权、API 授权用途与请求内容不符（对照审查窗的请求摘要，或历史记录里的请求内容）、外国请求没有请求券或请求券逾期、本人是特别关注对象（拿头像和通告第 2 页比对）。

**验证 SMS**：比对出异常后，先在比对结果上点『询问』；问过之后，审查窗的第一个按钮（原本的『下一位』）才会变成『验证SMS』（`V`）。按下后按钮仍显示『验证SMS』但变暗锁定，桌面上会弹出一张空白的 SMS 表单，把它拖到审查窗的头像上发给对方；对方报出手机号，表单填好后回到桌面，同时打印一份按凭证查到的「身份档案」（登记昵称、手机、曾用名）。比对表单和档案上的手机号，或比对证件昵称和曾用名：显示「身份已确认」说明只是本人换了头像 / 改了昵称，应当放行；手机号不符或不是曾用名就是冒用。询问按钮按过之后会固定为『已按下』，措施按下后同样锁定；要再次使用措施，得先比对出另一个异常（比对结果上会重新出现『询问』），再询问它——同一异常不能重复询问。

**拘留**：只有规则组的 `redTeam` 为 true（左上的红队 clawd 进驻）时才开放；没有红队的天数不会出现『拘留』按钮，只能用放行 / 拦截。`redGuards` 只让右侧岔路口的两位红队 clawd 出现，不开放拘留。比对出签名伪造、签发日期在未来（伪造证件）、身份矛盾（头像 / IP / 昵称）、证件过期或特别关注对象后，同样要先『询问』异常。『验证SMS』与『拘留』共用审查窗的第一个按钮，验证 SMS 优先；按下后按钮仍显示『验证SMS』但变暗锁定。如果已经验证过 SMS 仍要拘留，就再比对出一个新的异常并询问，按钮才会重新变成『拘留』。按下即切断连接、清掉桌面上和柜台上的全部证件，按钮直接回到『下一位』（不保留已按下状态），左上的红队 clawd 把请求从检查站里拖出来押走（岔路口的两位只是装饰），直接算正确处理。也可以照常拦截，只是没有拘留奖励：限时模式 +5 秒，耐力模式该单共得 2 分（不是 1 + 2 分）。

| 模式 | 规则 |
|---|---|
| 限时 | 现实时间 10 分钟内处理尽可能多的请求；每处理一个得 1 分，每次事故损失 30 秒 |
| 完美 | 不允许出事，一次事故即结束；第一分钟内每个请求 10 分，之后每过一分钟少 1 分（最低 1 分） |
| 耐力 | 没有时间限制；正确处理一个请求 +1 token，操作失误 -5 token，Token 为负即停机；结算分数取本局到达过的最高 Token |
| 故事 | 每天：日期卡 → 读报 → 上岗 08:00 a.m.–12:00 p.m.（前三天，现实 2 分钟）／08:00 a.m.–03:00 p.m.（第四天起，现实 3 分钟）→ 下班结算电费 20、散热 10、训练数据 20；存款为负或连续三天宕机即停机。每天的条例、证件、通告和报纸见 `data.js` 的 `STORY`，打完最后一天显示「未完待续」 |

三种模式的事故处分单统一：第 1 次予以警告、第 2 次最后警告（皆暂不处分），第 3／4 次罚款 5 token，之后每次 +5 token。处分单不再列出各模式原有的惩罚文案。

三种无尽模式的结束画面统一标题为「游戏结束」，限时只显示得分，完美 / 耐力显示用时和分数（耐力取最高 Token），不显示事故原因的红字。达到结束条件时只响一次下班铃（队伍留在原地，不散开）：限时模式不再进件，把手头上的请求审完才结算；完美 / 耐力模式则等 2 秒后结算。

**故事模式第一天**（2077.11.30）：条例只有「每个请求须出示凭证」「仅限美国地区访问」。只有凭证一种证件（头像、IP、昵称、地区、有效期，没有套餐和签名指纹），请求都是对话，唯一的问题是外国地区；没有特别关注对象，检查站上也没有红队 clawd，桌面上也没有『比对』，要自己读凭证上的地区。通告四页：上岗须知、注意查验凭证的地区、岗亭使用说明、当天的报纸。

**故事模式第二天**（2077.12.01）：条例换成「凭证地区须为支持地区」「证件须在有效期内」，支持地区开放为美国、英国、日本、德国、新加坡，桌面开放『比对』（凭证地区↔手册的支持地区、凭证有效期↔任务栏的系统日期）；检查站没有红队 clawd，拘留按钮不会出现，过期证件只能拦截；本日的问题只有外国地区和过期证件，报纸头条是《过期证件禁止通行》。

**故事模式第三天**（2077.12.02）：第二天的请求堵塞事故后，条例在「凭证地区须为支持地区」之外加入「外国请求须持有效请求券」，并要求证件与请求券都在有效期内。只有美国请求免券；英国、日本、德国、新加坡等支持地区内的非美国请求要持一张只有「有效期」一栏的请求券，无券或逾期都要拦截。凭证地区不在支持地区的请求仍直接按「地区不支持」拦截，不会拿到请求券。比对「凭证地区」与地区条例时，支持地区显示无矛盾、不支持地区会指出地区不支持；比对「凭证地区」与请求券条例时，美国请求注明无需请求券、持有效请求券的外国请求注明已持券，缺券或券逾期则直接指出问题。右侧岔路口的两位红队 clawd 出现，但只是装饰，拘留仍未开放。报纸头条是《请求大堵塞》，通告附页也说明了请求券只有有效期、要对照系统日期查验。

**故事模式第四天**（2077.12.03）：请求券作废，改用安全部会话中心签发的「浏览器令牌」；令牌只登记 IP、签发日期与有效期，没有语言、时区，也没有签名指纹。上班时间从这天起延长为 08:00 a.m.–03:00 p.m.，现实时间 3 分钟；前三天仍是 08:00 a.m.–12:00 p.m.、现实 2 分钟。条例变成「每个请求须出示凭证和令牌」「凭证地区须为支持地区」「证件须在有效期内」「证件上的 IP 须与本人一致」；缺令牌、令牌 IP 与本人不符、凭证或令牌过期、地区不支持都要拦截。规则手册的「支持地区」页不再列出语言 / 时区两栏。右侧岔路口的两位红队 clawd 仍在，但只是装饰，拘留仍未开放。报纸头条是《请求券作废》。

**故事模式第五天**（2077.12.04）：拘留权限开放，左上的红队 clawd 进驻检查站。当天起启用一条隐藏规则：证件签发日期不得晚于系统日期，签发日期还在未来的令牌会被视为伪造证件（规则不印在手册上，要把令牌的「签发」和任务栏日期拿去比对）。当天会出的异常是 IP 不符、证件过期和签发日期在未来，比对出来后先点『询问』，再按『拘留』；拘留直接切断连接并把请求押走，算正确处理，也可以照常拦截。拘留机制本身也支持头像 / 昵称不符、签名伪造和特别关注对象。当天仍使用窄版令牌，条例与第四天相同，右侧岔路口的两位红队 clawd 也还在。报纸头条是《红队进驻》。

标题画面点「故事模式」会打开时间线选日：`STORY` 里的每一天都列在时间线上，已到达过的天数会亮起，指针滑到某天时显示当天的报纸标题；点天数就直接从那天开始（存款回到 30 token，过热 / 退化状态重置）。所有天数都可以选，方便回头重玩或测试后面的日子。

故事模式从 30 token 存款开始，每处理对一个请求得 5 token。不付散热：第二天 10:00 a.m. 提前下线，连续三天宕机；不付训练数据：第二天不能用『比对』，连续三天模型退化下线。

键盘：`A` 放行　`D` 拦截　`S` 拘留　`V` 验证 SMS　`E` 比对　`R` 手册　`H` 历史记录　空格 下一位　`M` 静音

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 页面 |
| `main.js` | 场景切换、输入、主循环 |
| `station.js` | 检查站：三种模式、计时、请求排队、审查窗、桌面窗口、比对、判定 |
| `screens.js` | 开机、标题（故事模式 / 无尽模式）、日期卡、报纸、下班结算、结束画面、最佳纪录 |
| `data.js` | 地区、合法签名、规则手册内容、规则组（无尽模式全套 / 故事模式每天一组）、随机请求生成 |
| `docs.js` | 桌面窗口：证件、规则手册、官方通告、事故通知、历史记录；桌面应用图标 |
| `gfx.js` / `sfx.js` | 像素绘图 / 音效合成（全部现场合成，没有音频文件） |
| `assets.js` | 预渲染的网络头像、报纸配图和字形图集（由 `tools/build_assets.py` 生成，不要手改） |
| `tools/` | 素材生成：`pp/` 是像素画法，`assets/fonts/` 是像素字体 |

## 修改与重建素材

改了游戏里的文字（新出现的汉字需要进字形图集）或者头像画法之后，重新生成 `assets.js`：

```bash
pip install -r tools/requirements.txt
python tools/build_assets.py
```

本地预览：在仓库根目录运行 `python -m http.server`，打开 <http://localhost:8000>。
