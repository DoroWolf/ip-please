<h1 align="center">IP, PLEASE · 风控检查站</h1>

<p align="center">
  Papers, Please 风格的像素小游戏。<br>
  你是一个部署在入口网关前的风控小模型。每一个请求都要先经过你，才能到达模型：放行合规的，拦截违规的。
</p>

- 三种无尽模式：限时 / 完美 / 持久（故事模式制作中，暂不开放）
- 手机横屏用手指、电脑用鼠标；也支持键盘
- 纯静态网页，不加载任何外部资源；下载仓库后直接双击 `index.html` 也能玩

## 画面

- **上方**：请求在风控检查站前排队（一开场就爆满，不显示人数），出站后绿色向上是放行、红色向下是拦截
- **左下 · 审查窗**：节点接入时显示 Ta 的网络头像（像素滤镜）、节点编号、昵称、请求类型和摘要；柜台上放着递过来的证件和《规则手册》
- **右下 · 电脑桌面**：证件和手册都要拖到桌面上打开，拖回审查窗收起；任务栏上有手册、比对、放行、拦截和系统日期

世界观日期从 2078.01.01 开始。每次上岗，桌面会先弹出安全部的官方通告。点第一次『下一位』之前，时间不会流逝。

## 玩法

下一位 → 把证件拖到桌面 → 对照《规则手册》→『比对』两项信息找矛盾（可以追问）→ 放行 / 拦截。

三种证件，每张都带数字签名（签发机构、指纹、图案），须与手册第 2 页的式样完全一致：

| 证件 | 内容 | 什么时候要 |
|---|---|---|
| 凭证 | 头像、节点编号、昵称、地区、有效期 | 每个请求 |
| 令牌 | 节点编号、签发日期、有效期 | 每个请求 |
| API 授权 | 持有人、节点编号、用途、有效期 | 请求类型为 API 调用时 |

常见问题：地区不支持、头像不符、节点编号 / 昵称差一点、证件过期（对照任务栏日期）、签名伪造、API 调用没带授权。

| 模式 | 规则 |
|---|---|
| 限时 | 现实时间 10 分钟内处理尽可能多的请求；每处理一个得 1 分，每次事故损失 30 秒 |
| 完美 | 不允许出事，一次事故即结束；第一分钟内每个请求 10 分，之后每过一分钟少 1 分（最低 1 分） |
| 持久 | 没有时间限制；正确处理一个请求 +1 分，操作失误 -5 分，分数为负即停机。不显示世界观时间 |
| 故事 | 制作中，暂不开放。保留原持久模式的每日流程与 token 结算：每天 01:00 a.m.–01:00 p.m.（现实 5 分钟），下班结算电费 20、散热 10、训练数据 20；存款为负或连续三天宕机即停机 |

三种模式的事故处分单统一：第 1 次予以警告、第 2 次最后警告（皆暂不处分），第 3／4 次罚款 5 token，之后每次 +5 token。处分单不再列出各模式原有的惩罚文案。

故事模式（暂不开放）从 30 token 存款开始，每处理对一个请求得 5 token。不付散热：第二天 10:00 a.m. 提前下线，连续三天宕机；不付训练数据：第二天不能用『比对』，连续三天模型退化下线。

键盘：`A` 放行　`D` 拦截　`E` 比对　`R` 手册　空格 下一位　`M` 静音

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 页面 |
| `main.js` | 场景切换、输入、主循环 |
| `station.js` | 检查站：三种模式、计时、请求排队、审查窗、桌面窗口、比对、判定 |
| `screens.js` | 开机、标题（选模式）、日期卡、下班结算、结束画面、最佳纪录 |
| `data.js` | 地区、合法签名、规则手册内容、随机请求生成 |
| `docs.js` | 桌面窗口：证件、规则手册、官方通告、事故通知 |
| `gfx.js` / `sfx.js` | 像素绘图 / 音效合成（全部现场合成，没有音频文件） |
| `assets.js` | 预渲染的网络头像和字形图集（由 `tools/build_assets.py` 生成，不要手改） |
| `tools/` | 素材生成：`pp/` 是像素画法，`assets/fonts/` 是像素字体 |

## 修改与重建素材

改了游戏里的文字（新出现的汉字需要进字形图集）或者头像画法之后，重新生成 `assets.js`：

```bash
pip install -r tools/requirements.txt
python tools/build_assets.py
```

本地预览：在仓库根目录运行 `python -m http.server`，打开 <http://localhost:8000>。
